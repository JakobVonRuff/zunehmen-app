# Zunehmen

Kleine iPhone-Web-App: ein täglicher Essensplan zum gesunden Zunehmen mit Abhak-Liste, Einkaufsliste und Regeln. Haken werden nur auf dem eigenen Gerät gespeichert.

Installieren: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Allgemeiner Ernährungsplan, kein Ersatz für ärztlichen Rat.
